# Fonts

No font files were shipped with this brand. Matches were chosen from Google Fonts based on the wordmark in the provided logo JPEG.

## Substitutions
- **Display / Wordmark** → **Prata** (elegant serif, high contrast, matches the "OXFORD" wordmark's transitional-serif feel). Backup: **Cormorant Garamond**.
- **Body / UI** → **Inter** is banned per house style. We use **Manrope** for UI (geometric, clean, pairs well with a classic serif) and **Instrument Sans** as an alternate.
- **Accents / small caps** → **Prata** uppercase tracked out (matches "SOLUÇÕES DIGITAIS" treatment in the logo).

## ⚠️ Flag for the user
These are **best-guess substitutions** from the logo image. Please send the actual Oxford font files (TTF/OTF/WOFF2) if they exist — the wordmark may be a custom cut of Trajan/Cinzel/Bodoni, which would change the display font choice.
