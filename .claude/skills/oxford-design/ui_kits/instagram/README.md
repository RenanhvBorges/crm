# Instagram — UI Kit

The content engine. Templates for the post formats that dominate Oxford's weekly calendar (see `conteudo/analise-semanal-concorrentes-2026-04-16.md`).

**Templates included**
- **Feed grid (3×3)** — alternation rule: blue full-bleed / cream editorial / terracotta break
- **Carousel cover — hook** (`p-hook`): blue full-bleed, display serif, italic terracotta span
- **Case post** (`p-case`): cream bg, big terracotta stat, italic serif quote, brand mark
- **Carousel cover — question** (`p-q`): white, display serif question with terracotta highlight
- **Carousel inner slide** (`p-slide`): numbered page, red flag callout, progress dots
- **Reel — talking head** (`r-talk`): CEO direct-to-camera with pinned caption
- **Reel — reframe** (`r-big`): terracotta full-bleed, "X vs Y" concept
- **Reel — bastidor** (`r-bts`): grainy black, reunião de estratégia style

**Aspect ratios used**
- Post: 1080×1350 (4:5)
- Reel: 1080×1920 (9:16)
- Feed cell: 1080×1080 (1:1)

Built per the voice guidelines: no emoji, CEO-forward, numbers-first.
