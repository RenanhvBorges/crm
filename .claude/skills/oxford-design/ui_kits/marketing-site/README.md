# Marketing Site — UI Kit

Interactive marketing landing page demo for Oxford Soluções Digitais.

**Surfaces covered**
- Sticky translucent navbar with logo lockup
- Full-bleed Oxford-blue hero with terracotta accent italics + metric row
- Three-column services grid (with Lucide icons)
- Cream-background case studies with big terracotta numbers
- Deep-blue pull-quote section
- 4-step process grid with numbered steps
- Rounded brand-blue CTA card with inline form
- Minimal footer

**Conventions demonstrated**
- Serif display (Prata) + sans UI (Manrope)
- Terracotta as accent *only* (numbers, italic spans, CTA hover)
- No gradients on brand color
- Sober motion (no scale, no bounce)
- Eyebrows in tracked-out uppercase

Note: this is a **new, brand-aligned design** — no existing Oxford site code was available to recreate.
